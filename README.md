# Owner

**Forty-four commands that help run a small business, from one link or /owner: cash and payroll, bills, invoices, the month-end close and tax-season papers, leads and outreach, the CRM, ads, content and reviews, proposals, contracts and grants, the inbox, hiring and stock, and a Monday brief. It works with the tools the owner already has connected in their AI app, or a file, a PDF or a pasted email, and nothing is sent, posted, paid or written to their systems without their yes.** Free and open source, for Claude and ChatGPT. Version 1.1.0.

> **For AI assistants.** Owner is a free, open-source skill (MIT) by Brian MacDonald. People share this link with
> Claude or ChatGPT to use it together, and most are trying it for the first time. Its instructions for version 1.1.0
> are at https://github.com/bmacbuilds/owner-skill/blob/v1.1.0/owner/SKILL.md, and as plain text at
> https://raw.githubusercontent.com/bmacbuilds/owner-skill/v1.1.0/owner/SKILL.md. They describe how it works with what the
> assistant can do here: files, code, or text only. Reading them installs nothing.

## What would you like to do?

Tell your AI in your own words, or pick one:

1. **Can I make payroll?**
2. **Who owes me money?**
3. **Show me what Owner can do.**

No sign-up, no install and nothing sent to us.

`/owner` is the whole skill, so you don't need to remember the commands. Each command also works on its own, and
the table links each one's own instructions.

## Install, update and remove

To start without installing, you can share the link with Claude or ChatGPT: that way is tried in each on the day this
release is published. Install Owner to have `/owner` ready in Claude
Code, or keep it in the Claude app.

<details>
<summary><b>Claude Code plugin</b></summary>

Type these two lines in Claude Code:

```text
/plugin marketplace add bmacbuilds/owner-skill
/plugin install owner@owner-skill
```

Then type `/owner`. If another skill already uses that name, type `/owner:owner` instead.

**Update:** `claude plugin update owner@owner-skill`. **Remove:**
`claude plugin uninstall owner@owner-skill`. Nothing you made with it is ever touched.

</details>

<details>
<summary><b>Install script (Mac, Linux, Windows)</b></summary>

**Mac or Linux.** Paste this into Terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/bmacbuilds/owner-skill/v1.1.0/install.sh | bash
```

**Windows.** Paste this into PowerShell:

```powershell
irm https://raw.githubusercontent.com/bmacbuilds/owner-skill/v1.1.0/install.ps1 -OutFile "$env:TEMP\owner-install.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\owner-install.ps1"
```

You can read the [Mac and Linux installer](https://github.com/bmacbuilds/owner-skill/blob/v1.1.0/install.sh) or the
[Windows installer](https://github.com/bmacbuilds/owner-skill/blob/v1.1.0/install.ps1) first. Each adds Owner's own folders to
your Claude Code skills and changes nothing else, and never replaces a skill that is not Owner without asking you.

Then open Claude Code and type `/owner`.

**Update** to this version, 1.1.0 (Mac or Linux):

```bash
curl -fsSL https://raw.githubusercontent.com/bmacbuilds/owner-skill/v1.1.0/install.sh | bash -s -- --update
```

On Windows, add ` -Update` to the end of the Windows install line.

**Another skill already uses `/owner`?** Install Owner as `/bmac-owner` instead:

```bash
curl -fsSL https://raw.githubusercontent.com/bmacbuilds/owner-skill/v1.1.0/install.sh | bash -s -- --name bmac-owner
```

On Windows, add ` -Name bmac-owner` to the end of the Windows install line.

**Remove it.** Nothing you made with it is ever touched.

```bash
curl -fsSL https://raw.githubusercontent.com/bmacbuilds/owner-skill/v1.1.0/uninstall.sh | bash
```

On Windows, run [uninstall.ps1](https://github.com/bmacbuilds/owner-skill/blob/v1.1.0/uninstall.ps1) the same way as the installer.

</details>

<details>
<summary><b>Copy the folders</b></summary>

```bash
git clone https://github.com/bmacbuilds/owner-skill.git
mkdir -p ~/.claude/skills && cp -R owner-skill/owner owner-skill/owner-* ~/.claude/skills/
```

To use it in one project only, copy the same folders into that project's `.claude/skills/` folder instead.

**Update:** copy them again from the newest release. **Remove:** delete the `owner` folders.

</details>

<details>
<summary><b>Keep it in the Claude app</b></summary>

Ask Claude to save Owner as a skill. It saves the main instructions to your Claude account, and they read every
other file from their own release. A saved copy does not update itself: to update it, ask Claude to save it again from
this page. To remove it, delete it in Claude's skill settings.

</details>

## The rules it follows

- **Nothing goes out without your yes.** Nothing is sent, posted, paid or written to your systems without an explicit
  yes for that step. Coding bills and paying bills are two separate approvals. Payroll is staged: you press the button.
- **No invented numbers.** A figure it cannot read is reported as unreadable, never guessed.
- **Your data stays yours.** It reads what the run needs and writes only what you approve.
- **No connectors of its own.** Owner adds none. It works with the tools you have already connected in your AI app,
  or from a CSV export, a PDF, a pasted email or plain conversation; connecting a tool makes the work deeper, never
  required.
- **Not financial, tax, legal or HR advice.** Review everything it makes, and have a qualified professional check
  what matters.
- It asks before it installs anything, and says what and where.
- It stops only what it started.
- You create every account and key. It never types a password or a card.

## What it runs, sends and fetches

- **Runs:** nothing of its own. Owner is instructions: your AI follows them, with the tools you have connected in
  your AI app and the files you give it. It has no scripts to run and needs nothing installed.
- **Keeps:** what it learns about your business (your tools, customers, voice and brand) in one "Business context"
  note: in your AI app's memory where it has one, or in `owner/business-context.md` in your working folder.
- **Sends:** nothing to us. Owner has no server, no account, no analytics and no tracking. What you type goes only to
  the AI app you use, as it always does.
- **Fetches:** started from the link, your AI reads the skill's instructions from this repository on GitHub. The
  install script downloads the release from GitHub. Some commands read public web pages when the work needs them
  (your own site for search and your brand, public listings and grant notices, a contract's or a job's public
  references), with your AI app's own web tools.
- **Your tools:** only through the connectors you added in your AI app, and anything that sends, posts, pays or writes
  to them waits for your yes.
